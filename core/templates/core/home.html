🚗 Vehicle Booking System

Your one-stop solution for vehicle rentals

API Endpoints

POST /api/accounts/register/ - Register new user
POST /api/accounts/login/ - Login user
GET PUT /api/accounts/profile/ - View/Update profile
GET POST /api/vehicles/ - List/Create vehicles
GET PUT DELETE /api/vehicles/{id}/ - Vehicle details
GET POST /api/bookings/ - List/Create bookings
GET PUT DELETE /api/bookings/{id}/ - Booking details
GET /admin/ - Admin panel
